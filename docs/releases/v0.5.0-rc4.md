# LocalForge v0.5.0 RC4 — prerelease

This is a **release candidate**, not the stable v0.5.0 release. It has passed automated GitHub CI, including an end-to-end Windows installer test, but still needs acceptance testing on actual user machines and with real local models.

## What's included

- LocalForge multi-agent control plane: Plan/Act collaboration, distributed fan-out, task coordination and recovery.
- Mesh discovery and connected Companion workflows for project and terminal operations.
- Per-workspace persistent memory, file indexing, and local search.
- Persistent interactive terminals with working-directory and environment persistence.
- Native Windows Companion installer and tray application.
- A compiled Windows Companion using Bun's native ConPTY backend. The installer includes a narrowly scoped Windows console-interrupt helper for reliable Ctrl+C during interactive commands.
- Linux source-based Companion usage remains available; this prerelease does **not** include a Linux desktop installer.

## Windows prerelease download

**Windows 10/11 x64:** `LocalForge-Companion-Setup-0.5.0.exe` (unsigned).

The filename uses the Companion package version 0.5.0; the **GitHub tag** `v0.5.0-rc4` identifies this release candidate. Download `SHA256SUMS.txt` alongside the installer and compare its checksum before running it.

The installer is **not code-signed**. Windows SmartScreen may display an unknown-publisher warning. Do not disable Windows Defender or other security software. See [Windows installation and troubleshooting](https://github.com/kayock/Kayocks-Local-Forge/blob/main/docs/WINDOWS_INSTALL.md).

## Independently verified on GitHub-hosted Windows runners

[Authoritative Windows installer and installed-product verification](https://github.com/kayock/Kayocks-Local-Forge/actions/runs/45042085932) **passed**, including:
- Windows-native build and SHA-256 verification of the downloaded installer.
- Silent installation of that exact installer, installed file and Start Menu shortcut checks.
- Installed Companion startup, /health, and genuine pairing.
- Real PowerShell ConPTY terminal launch, output, persistent cwd and environment, terminal resize and **Ctrl+C interrupt recovery**.
- PTY session cleanup, tray process startup attempt, and silent uninstall.

[Production IDE build, Linux preview cross-build, and Windows candidate smoke checks](https://github.com/kayock/Kayocks-Local-Forge/actions/runs/45042085906) also **passed**.
[Companion control-plane checks](https://github.com/kayock/Kayocks-Local-Forge/actions/runs/45042089924) **passed**.

## Acceptance testing still needed

- Windows 10/11 desktop installation and upgrade on real user hardware, including interactive tray UI and SmartScreen behavior.
- Real local inference and model-provider discovery with existing models.
- LAN mesh/multi-machine collaboration and distributed fan-out with genuine projects.
- Linux installation and workflows outside GitHub's runner environment.

The automated tests do **not** establish that all GUI and real-hardware interactions have passed. Report release-candidate bugs before promoting to stable v0.5.0.
